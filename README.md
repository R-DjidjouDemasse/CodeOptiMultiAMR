# CodeOptiMultiAMR
This code package includes three files used to reproduce the figures in the article https://hal.science/hal-04894904. 
The files WithinHostQUASAROPTI.m and MainFunction_DynaWithA_and_DynaWithAB.m contain the code for the intra-host and inter-host dynamics, respectively. 
The file Figures.m is responsible for generating the figures presented in the article.
